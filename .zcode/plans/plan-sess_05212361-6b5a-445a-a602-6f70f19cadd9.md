## Plan: Rename Booking Addon Order → Booking Addon + Add Link Fields on SO/SI

### Problem
The user wants:
1. **Rename** the "Booking Addon Order" doctype → "Booking Addon" (and the existing "Booking Addon" child doctype → "Booking Addon Item" to resolve the name collision)
2. **Add a Link field** (`custom_booking_addon`) on Sales Order and Sales Invoice pointing to the new "Booking Addon" (header), with the SI field populated "bila bayaran penuh" (when the SI is auto-created from a fully-paid SO)

### Phase 1: DB-level doctype rename (via `bench execute`)

Run two `frappe.rename_doc("DocType", ...)` calls sequentially:
1. `frappe.rename_doc("DocType", "Booking Addon", "Booking Addon Item")` — frees the name "Booking Addon", auto-updates all Link field `options` and `link_doctype` references from "Booking Addon" → "Booking Addon Item" (including the child's self-reference, the header's `links` entry, Trip Addon Package's `links` entry, and the SI's `custom_booking_addon` options)
2. `frappe.rename_doc("DocType", "Booking Addon Order", "Booking Addon")` — auto-updates all references from "Booking Addon Order" → "Booking Addon" (including the child's `addon_order` Link field options, workspace/sidebar links, API code references, and the booking_engine lookup)

This handles DB table renames (`tabBooking Addon` → `tabBooking Addon Item`, `tabBooking Addon Order` → `tabBooking Addon`) and all Link field option updates automatically.

### Phase 7: Update checkout flow — `addon_manager.py`

Restructure `checkout_addons()` to create the Booking Addon (header) BEFORE the Sales Order, so the SO can carry `custom_booking_addon`:

```python
# 1. Create Booking Addon (header) first — without sales_order
order = frappe.get_doc({
    "doctype":      "Booking Addon",
    "booking":      booking.name,
    "status":       "Pending",
    "currency":     so_currency,
    "total_amount": grand_total,
})
order.insert(ignore_permissions=True)

# 2. Create Sales Order with custom_booking_addon pointing to the order
so = frappe.get_doc({
    "doctype":              "Sales Order",
    "customer":              booking.customer,
    "custom_booking":        booking.name,
    "custom_booking_addon":  order.name,   # ← NEW: reverse link
    ...
})
so.insert(ignore_permissions=True)
so.flags.ignore_permissions = True
so.submit()

# 3. Set the order's sales_order (reverse link on the header)
order.db_set("sales_order", so.name)

# 4. Create Booking Addon Item rows (children)
for l in validated_lines:
    frappe.get_doc({
        "doctype":             "Booking Addon Item",
        "addon_order":         order.name,
        ...
    }).insert(ignore_permissions=True)
```

Also update the child doctype name from `"Booking Addon"` → `"Booking Addon Item"` in the `frappe.get_doc` calls.
