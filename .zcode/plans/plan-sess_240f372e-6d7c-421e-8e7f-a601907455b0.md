# Plan: Create `/booknow` — Booking Wizard (Rarecation Theme)

## Objective
Create `/booknow` page — **same system flow & rules** as `/booking`, but **new interface** matching Rarecation's public theme (cruise/tour style).

## Key Principle
| Aspect | Source | Detail |
|--------|--------|--------|
| **System Flow** | Copy from `booking.js` | 5-step wizard: Select Date → Rooms → Billing → Payment → Confirm |
| **Business Rules** | Copy from `booking.js` | Cruise slot-model vs Tour age-model, OTP gate, voucher/affiliate, Stripe |
| **API Calls** | Identical | All `travel_booking.api.booking.*` endpoints unchanged |
| **State Management** | Identical | sessionStorage key, deep-link params, state object shape |
| **Visual Theme** | **NEW** — match cruise/tour | Gold `#C9A84C`, dark `#1E1C18`, cream `#F7F5F0`, font Rubik/Jost/Satisfy |
| **UI Components** | **NEW** — redesigned | Cards, buttons, steppers, form inputs in Rarecation style |

## Files to Create

### 1. `travel_booking/www/booknow.py` — Controller
Clone of `booking.py` controller:
- `get_context()` reads `?trip_master=` & `?trip_group_date=`
- Calls `get_ready_bundle()` from `utils.trip_catalog`
- Passes: `trips`, `trip_group_dates`, `trip_packages`, `trip_is_cruise`, `company_currency`, `company_symbol`, `csrf_token`
- Sets `context.title = "Book Now — Rarecation"`, `context.no_cache = 1`

### 4. `travel_booking/public/js/booknow.js` — Client Logic

- Same step navigation (`showStep()`)
- Same API call pattern (all endpoints unchanged)
- **Changed**: DOM selector prefixes from `#step*` / `.room-*` to `.bnw-*`
- **Changed**: Render functions output new HTML structure (Rarecation styled)
- **Same**: `priceRoomSelection()`, `capFor()`, discount calculation, state management
- **Same**: `confirm_booking()` payload construction
- **Same**: Stripe return handling, confirmation polling
