### 2.2 Add OCR Functions in traveller_billing.js

**New functions:**
```
initReceiptOCR()          — Lazy-init Tesseract worker (called once)
extractReceiptData(file)  — Run OCR on uploaded image, return parsed data
parseBankSlip(text)       — Extract date, reference from OCR text using MY bank patterns
autoFillFromReceipt(form, file)  — Main orchestrator called on file upload
```

**Malaysian Bank Slip Parsing Patterns:**

| Field | Patterns | Output Format |
|-------|----------|---------------|
| Date | `DD/MM/YYYY`, `DD-MM-YYYY`, `D MMM YYYY` | `YYYY-MM-DD` (for date input) |
| Reference | `Ref/Reference/No/M2U/FPX` + alphanumeric | String (for ref input) |
| Raw Text | All OCR output | Paste into Notes textarea |

**Date regex examples:** `/(\d{1,2})[\/\-](\d{1,2})[\/\-](\d{4})/`
**Ref regex examples:** `/(?:Ref(?:erence)?|No\.?|M2U)\s*[:\.\-]?\s*([A-Z0-9]{6,20})/i`

### 2.3 Integrate into File Upload Handler (wirePaymentForms)
When user selects a file in manual payment panel:
1. Show "Reading receipt..." status on upload zone
2. If image file → run Tesseract.js OCR
3. Parse extracted text for date + reference
4. Auto-fill:
   - Reference No. field ← detected reference
   - Transfer Date field ← detected date (YYYY-MM-DD format)
   - Notes field ← full raw OCR text
5. Show "✓ Auto-filled from receipt" badge
6. If PDF or OCR fails → silently skip (user enters manually)

### 2.4 UI Feedback Elements
- Upload zone shows spinner/text while processing
- Green badge appears near Notes: "📝 Extracted from receipt"
- Fields that were auto-filled get subtle highlight (green border briefly)
