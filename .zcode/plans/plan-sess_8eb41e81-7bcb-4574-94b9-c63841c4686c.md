# Pelan: Buang `custom_share_traveller_cabin` & `custom_share_traveller_reservation` — Additional Traveller guna Booking + `custom_booking` + Booking Reservation sahaja

## Model sasaran (seperti yang anda mahukan)

```
Booking sedia ada (BK...) ──< Sales Order (link: custom_booking SAHAJA)
      │
      └──< Booking Reservation (slot pax, di bawah Booking yang SAMA)
              • cabin ditentukan dari panel cabin portal (dipadankan room_id roommate)
              • dicipta HANYA selepas SO tambahan dibayar penuh (hook Payment Entry)
```

- **Dua custom field Sales Order dibuang** sepenuhnya (field + data + rujukan kod).
- Maklumat cabin dibawa dalam **item SO description** — corak sedia ada `Trip | Group | Room Category | Cabin N | Pax Type` (sudah menjadi "sumber tunggal layout" dalam `_cabin_layout_from_so`).
- **Deteksi "SO traveller tambahan"** tanpa custom field: SO yang berkaitan booking (ada `custom_booking`), **bukan primary SO**, dan ada item `TRAVEL-PKG` (SO addon guna item berbeza).
- **Idempotency + traceability** menggantikan tugas `custom_share_traveller_reservation`: field baharu **`sales_order` (Link → Sales Order)** pada doctype aplikasi sendiri `Booking Reservation` — setiap slot tahu SO mana yang membiayainya, dan connection sidebar SO papar slot tersebut (lebih "terbuka" berbanding hidden marker).
- Tambah traveller dibuat **dalam panel cabin tertentu** di portal — cabin & roommate sudah ditetapkan; slot baharu auto dapat `room_id` sama dengan roommate (auto oleh `assign_room_id()` = `[booking_number]-Room_[cabin_no]`).

## Simulasi gerak kerja — Ali (single traveller) tambah traveller kemudian hari

**T0 — Booking asal:** Ali tempah cruise solo, 1 cabin "Balcony Cabin" pada kadar single RM2,000 (`price_adult_single`; `price_adult` = RM1,200). `confirm_booking` cipta **SO-PRIMARY** (submitted, `custom_booking = BK.26.09.001`, description item `"... | Balcony Cabin | Cabin 1 | Main Guest (Single)"`, `custom_room_privacy = Open Sharing`). Booking status Pending.

**T1 — Bayaran pertama:** Payment Entry submit → `_recompute_booking_status` → Booking Pending→Accepted → `_activate_booking` cipta **RES-1** (cabin 1, Main Guest, `room_id = RC...-Room_1`, `sales_order = SO-PRIMARY`). Cruise occupancy +1. Ali isi passport melalui `/traveller/travellers`.

**T2 — Kemudian hari, portal:** Ali buka halaman booking → panel **Cabin 1** (roommate: Ali, room_id RC...-Room_1) → butang "Add Traveller" aktif (occupancy 1/2, trip ada seats) → paparan: *"Twin-share RM1,200 − kredit single-supplement RM800 = **RM400**"*.

**T3 — Cipta order:** `create_additional_traveller_order` (re-validate server: kapasiti cabin, seats trip, pending SO) → cipta **SO-SHARE** (submitted): `custom_booking` sahaja, **tiada custom field share**; 1 item `TRAVEL-PKG` rate RM400, description `"... | Balcony Cabin | Cabin 1 | Main Guest (Additional) | twin share ... less credit ..."`. Redirect ke billing portal.

**T4 — Bayaran tambahan:** Ali bayar RM400 → Payment Entry submit → `_recompute_booking_status(SO-SHARE)` → aktivasi: SO bukan primary + ada item TRAVEL-PKG + fully paid + tiada reservation dengan `sales_order = SO-SHARE` → parse description (room_category "Balcony Cabin", **Cabin 1**) → insert **RES-2 di bawah Booking yang SAMA**: cabin 1, Main Guest, `guest_label = "Additional Traveller"`, `room_privacy = "Open Sharing"`, `sales_order = SO-SHARE`, `room_id` auto = **RC...-Room_1** (sama dengan roommate ✓). `validate_cabin_capacity`: 2 Main Guest ≤ capacity 2 ✓ → cruise occupancy +1, Trip Group Date refresh.

**T5 — Isi detail:** Slot kosong RES-2 muncul dalam `/traveller/travellers`; Ali isi sendiri atau hantar guest link/QR kepada kawan. `Booking.total_pax` auto = 2; cabin grid Desk hub tunjuk Cabin 1 = 2 pax.

**Kes khas:**
- Ali tak bayar SO-SHARE → RES-2 tidak wujud; SO pending tetap dikira dalam gate kapasiti/oversell; boleh bayar bila-bila melalui billing.
- Kredit meliputi penuh (net ≤ 0) → slot terus diaktifkan tanpa bayaran (kekal).
- Panel cabin **multi-pax** (bukan solo, ada kekosongan) → butang sama, harga = `price_adult` penuh tanpa kredit (kredit supplement hanya untuk cabin solo).
- B2B end-customer disekat (kekal). Extra Bed/Infant tidak termasuk (Main Guest sahaja).
