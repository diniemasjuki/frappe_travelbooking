# Pelan: Kad Traveller Putih + Butang Share Link dengan QR Code

## Ringkasan Tugas
Ubah halaman `/www/traveller/travellers?ref=###` supaya:
1. **Kad traveller berwarna putih** (bukan krem seperti sekarang)
2. **Setiap traveller ada butang share kecil** yang menjana link guest + popup QR code (seperti trip.html)

### 3. Python API: `travel_booking/api/portal_traveller.py`
**Tujuan:** Tamabah QR code generation kepada response `request_guest_passport_link`

Perubahan pada fungsi `request_guest_passport_link()` (baris ~1386):
- Selepas generate token dan sebelum return, tambah QR generation:
  ```python
  import qrcode, io, base64
  
  qr = qrcode.QRCode(version=1, box_size=10, border=2,
                      error_correction=qrcode.constants.ERROR_CORRECT_M)
  qr.add_data(link)
  qr.make(fit=True)
  img = qr.make_image(fill_color="black", back_color="white")
  buf = io.BytesIO()
  img.save(buf, format="PNG")
  qr_data_uri = "data:image/png;base64," + base64.b64encode(buf.getvalue()).decode()
  ```
- Return dictionary tambahkan key: `"qr_data_uri": qr_data_uri`

## Risiko & Mitigasi
1. **QR library tidak installed**: `qrcode` PyPI package perlu ada di environment. Jika belum, perlu `pip install qrcode`.
2. **CSS conflict**: Modal classes `.rc-share-*` mungkin conflict jika `trip_detail.css` tidak load di travellers page. Perlu pastikan CSS tersebut diload (atau salin styles ke `traveller.css`).
3. **Token regeneration**: Setiap klik share regenerate token (overwrite lama) — ini behaviour sedia ada, OK.
