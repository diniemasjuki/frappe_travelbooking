# Resources Management (Crew Availability) - Implementation Plan

## 📋 Overview
Buat sistem pengurusan resource (crew availabilities) dalam module `Resources Management` yang sedia ada (masih kosong). Sistem ini akan monitor & allocate slot available untuk crew, dan memaparkan dalam Gantt Chart & Calendar View (read-only).

---

## 🏗️ Architecture Design

### Data Model (3 DocTypes + 1 Page)

#### 1️⃣ **Crew** (Master Data)
**Lokasi**: `resources_management/doctype/crew/`

| Field | Type | Description |
|-------|------|-------------|
| crew_name | Data (reqd) | Nama penuh crew |
| user | Link → User | Link ke akaun Frappe User |
| email | Data | Auto-fetch dari user |
| phone | Phone | Nombor telefon |
| role_position | Select | Tour Leader / Driver / Guide / Staff / Other |

| department | Select | Operations / Transport / Hospitality |

| notes | Small Text | Catatan |

**Permissions**: Tour Manager (full), Tour Operator (read+write, no delete)

#### 2️⃣ **Crew Slot** (Allocation Container)
**Lokasi**: `resources_management/doctype/crew_slot/`

| Field | Type | Description |
|-------|------|-------------|
| slot_name | Data (auto) | Auto-generate: "{start_date} - {end_date}: {trip_name}" |
| start_date | Date (reqd) | Mula slot |
| end_date | Date (reqd) | Tamat slot |
| max_crew | Int (default:1) | Max crew boleh assign |
| current_crew | Int (read-only) | Bilangan crew dah assign |
| status | Select | Planned / Confirmed / Cancelled / Completed |
| trip_group_date | Link → Trip Group Date | Link ke trip |
| trip_name | Data (read-only) | Fetch dari trip_group_date |
| notes | Text | Catatan |

**Child Table**: `crew_allocations` → Crew Allocation (istable)

**Validation Logic**:
- ✅ end_date >= start_date
- ✅ Auto-status: Completed jika end_date < today
- ✅ Auto-calculate current_crew dari child table

---

#### 3️⃣ **Crew Allocation** (Child Table / Junction)
**Lokasi**: `resources_management/doctype/crew_allocation/`
**Type**: `istable: 1` (child table sahaja)

| Field | Type | Description |
|-------|------|-------------|
| crew | Link → Crew (reqd) | Crew yang di-assign |
| crew_name | Data (read-only) | Fetch nama crew |
| role_in_slot | Select | Role khusus untuk slot ni |
| allocation_status | Select | Assigned / Confirmed / Declined / Replaced |
| remarks | Small Text | Catatan |

**Critical Validation** (dalam Crew Slot controller):
```python
def validate_crew_conflicts(self):
    """Check setiap crew tak ada conflict dengan slot lain"""
    for alloc in self.crew_allocations:
        conflicts = frappe.get_all("Crew Allocation", 
            filters={
                "parent": ["!=", self.name],
                "crew": alloc.crew,
                "parenttype": "Crew Slot",
                # Overlap logic: existing slot overlaps with current
            })
        if conflicts:
            frappe.throw(f"Crew {alloc.crew_name} already assigned to another slot in this period!")
```

#### 4️⃣ **Resources Management Page** (Dashboard)
**Lokasi**: `resources_management/page/resources_management/`
**URL**: `/app/resources-management`

**Features**:
- 📊 **Gantt Chart View** (default)
  - X-axis: Timeline (Day/Week/Month zoom)
  - Y-axis: Crew list (setiap crew satu bar)
  - Bars: Colored by status (Planned=blue, Confirmed=green, Cancelled=red)
  - **Read-only** (tidak boleh drag/drop)
  - Click slot → show detail panel
  
- 📅 **Calendar View** (toggle)
  - Monthly grid view
  - Setiap hari show number of allocations
  - Click date → filter slots for that date
  - **Read-only**

- 🔍 **Filters**:
  - Date range picker
  - Crew filter (dropdown)
  - Status filter (Planned/Confirmed/etc)
  - Trip filter (link to Trip Group Date)

- 📋 **Detail Panel** (bawah chart):
  - Selected slot information
  - List of crew assigned
  - Quick actions (Edit Slot, View Trip)

**Technical Implementation**:
- Follow IIFE pattern: `window.ResourcesManagement`
- Use Frappe's built-in Calendar + Gantt (same as Trip Group Date Calendar)
- API endpoint: `travel_booking.resources_management.api.get_resources_data`
- CSS prefix: `.rm-*` (Resources Management)

## ⚙️ Key Business Rules

### Rule 1: No Double-Booking
```
Crew A tidak boleh dalam Slot B (1-15 Jan) DAN Slot C (10-20 Jan) serentak
→ Validation error semasa save Crew Slot
```

### Rule 2: Slot Capacity
```
Slot X (max_crew=3) hanya boleh assign maksimum 3 crew
→ Validation error semasa tambah row dalam child table
```

### Rule 3: Auto-Status Updates
```
- Jika end_date < today → status auto "Completed"
- Jika semua allocations "Confirmed" → slot status auto "Confirms"
- Jika slot cancelled → cascade cancel semua allocations
```

### Rule 4: Trip Link Integrity
```
Jika trip_group_date ditetapkan:
- Auto-fetch trip_name, departure_date, return_date
- Optional: validate slot dates within trip dates
```

frappe.views.calendar["Crew Slot"] = {
    field_map: {
        start: "start_date",
        end: "end_date",

        title: "slot_name",

    gantt_options: {
        readonly: true,  // SAFETY: disable moving
