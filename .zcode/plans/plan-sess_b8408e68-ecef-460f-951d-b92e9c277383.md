# Revamp docs.html — Aliran Pendaftaran Traveller Baru

## Kajian semasa

- `docs.html` (www page, `/traveller_portal/booking_traveller/docs?ref=&slot=`) — wizard upload passport + form 4 tab (Info, Passport, Visa, Health), PDPA checkbox dalam tab Health.
- `portal_traveller_page.js` — satu `saveTraveller()` menghantar semua medan setiap kali; `save_booking_traveller` server menimpa SEMUA medan Traveller pada setiap save (nilai kosong akan padam data section lain — tak boleh dipakai untuk save per-section).
- `check_traveller_passport` — matching: image sha256/dhash DULU, baru passport_no, kemudian IC. Tidak ada normalisasi A-Z0-9.
- Traveller controller `set_uppercase` uppercase tapi TIDAK buang simbol.

## Perubahan

### 1. Backend — `travel_booking/api/portal_traveller.py`

**a. Normalisasi ID (spec 2):** helper baharu
`_normalize_id(v) = re.sub(r"[^A-Z0-9]", "", (v or "").upper())`
- Digunakan pada `ic_number` & `passport_no` dalam `save_booking_traveller` sebelum simpan (data baru bersih A-Z0-9).
- Digunakan dalam `check_traveller_passport` untuk nilai extracted MRZ/OCR.

**b. Susunan matching (spec 2.a/2.b):** dalam `check_traveller_passport`, tukar urutan kepada:
1. `passport_no` normalized (fetch & banding dalam Python supaya simbol lama turut match)
2. `ic_number` normalized
3. (fallback terakhir) image sha256/dhash — kekal sebagai jaring keselamatan untuk rekod lama yang tiada passport_no boleh dibaca OCR.

**c. Save per-section (spec 3.c/4.d/5.b):** `save_booking_traveller` diterima parameter `section` (`"passport" | "contact" | "health"`):
- `passport`: first/last name, gender, dob, nationality, ic, passport_no, passport_expiry + fail passport. Wajib first/last/IC (cipta Traveller + link ke Booking Reservation seperti sekarang).
- `contact`: email, phone, emergency contact (3 medan) + visa photo. Slot mesti sudah ada traveller linked (lookup ikut `slot.traveller`); hanya medan section ini dikemas kini — TIDAK menimpa medan section lain (fix masalah padam data).
- `health`: dietary, medical, special_needs, wheelchair, medicine_treatment — sama corak.
- PDPA consent kekal wajib pada SETIAP save (checkbox dipindah ke bar bawah), audit Comment sekali per Traveller kekal.

**d. Butang pengesahan akhir (spec 6):** endpoint baharu `confirm_traveller_documents(booking_number, slot_name)`:
- Sahkan milikan booking/slot (corak sedia ada).
- Validasi kelengkapan: nama, IC, passport_no + expiry, passport image on file, phone, emergency contact lengkap.
- Set `document_status = "Pending"` pada slot + `Traveller.status = "Pending"` (sedia untuk admin verify) + Comment audit "Documents confirmed complete by customer via portal".

### 2. Frontend HTML — `docs.html`

- Wizard Langkah 1 kekal (upload → check → found/new) — sudah patut spec 1; "system semak gambar boleh dibaca" = OCR gagal total → mesej minta upload semula.
- Form disusun semula kepada **3 tab**:
  - **1 · Passport** — nama (first/last/full), IC, nationality, DOB, gender, passport no/expiry (kekal validity badge 6-bulan), upload passport copy. Button: `← Back` / **Save Passport Section** / `Next: Contact Info →`.
  - **2 · Contact Info** — email, phone (intl-tel-input), emergency contact (nama/phone/relationship), **visa photo upload** (dipindah dari tab Visa lama; tab Visa dibuang). Button: `← Back` / **Save Contact Section** / `Next: Health →`.
  - **3 · Health** — dietary, medical, medicine/treatment, special needs, wheelchair. Button: `← Back` / **Save Health Section**.
- **Bar bawah di luar panel (spec 6):** `← Back to travellers` + checkbox Privacy Notice + butang **"✓ I confirm all information is complete"** (cadangan nama; panggil `confirm_traveller_documents`, papar hasil validasi, redirect ke senarai slot selepas berjaya).
- Traveller lama (slot sudah filled): buka terus tab Passport dengan maklumat sedia ada boleh di-edit (3.b).

### 3. Frontend JS — `travel_booking/public/js/portal_traveller_page.js`

- `TVL_TAB_ORDER = ['passport', 'contact', 'health']`.
- `saveTraveller(section)` — hanya hantar medan section berkenaan + `section` param; validasi inline hanya untuk medan section itu; notis "section saved".
