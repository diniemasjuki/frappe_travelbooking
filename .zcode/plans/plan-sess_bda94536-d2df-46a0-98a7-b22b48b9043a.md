## Phase 2: Apply Fixes (if bugs found)

### Fix #1: Add "Abandoned" status to Kanban columns
**File:** `travel_booking/api/booking_hub.py`
**Line:** ~23 (`get_booking_status_filters()`)

**Change:**
```python
def get_booking_status_filters():
    return ['Pending', 'Accepted', 'Processing', 'Confirmed', 'Completed', 'Abandoned']
```

**Why:** Currently "Abandoned" bookings are fetched from DB but dropped during grouping because no column exists for them.

---

### Fix #2: Fix payment reference field mismatch
**File:** `travel_booking/travel_booking_management/page/booking_hub/booking_hub.js`
**Line:** ~1112 (`render_payment_subtab`)

**Change:**
```javascript
// Before:
const ref = pay.reference_no || "-";

// After:
const ref = pay.reference || "-";
```

**Why:** API returns key `reference`, not `reference_no`.

### Fix #3: Fix addon disabled field typo
**File:** `travel_booking/travel_booking_management/page/booking_hub/booking_hub.js`
**Line:** ~1611 (addon catalog rendering)

**Change:**
```javascript
// Before:

// After:
if (addon.disable) { ... }
```

**Why:** API returns field `disable`, not `disabled`.
