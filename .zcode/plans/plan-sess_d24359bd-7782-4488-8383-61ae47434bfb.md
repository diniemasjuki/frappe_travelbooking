# Pelan: Butang "Add Traveller" dalam Senarai Cabin + Modal Pilih Kategori

## Latar semasa
- Page `/traveller/travellers` (mod senarai, `traveller_travellers.js`) ada panel atas **"Add a Traveller to Your Cabin"** (`loadShareCabins()` → `get_shareable_cabins`) dan panel bawah **"Add a New Cabin & Traveller"** (`loadNewCabinOptions()`).
- Backend `travel_booking/api/cabin_sharing.py`: `create_additional_traveller_order` sedia insert + **submit Sales Order terus**, kemudian redirect ke billing (atau reload bila `fully_covered`). Harga sentiasa kadar adult.
- Kategori harga cruise (share hanya untuk cruise): Main Adult (`price_adult`), Extra Bed (`price_upperberth`), Infant (`price_infant`) — semua sedia dalam `_get_pricing_map()`.

## A. Backend — `travel_booking/api/cabin_sharing.py`

1. **`get_shareable_cabins`** — tambah senarai `categories` pada setiap cabin dalam respons:
   - `main_adult` / "Main Adult" — kadar `price_adult`; bila cabin masih solo, net = `max(adult − excess_credit, 0)` (kredit twin-share).
   - `extra_bed` / "Extra Bed" — kadar `price_upperberth` penuh (tiada kredit).
   - `infant` / "Infant" — kadar `price_infant` penuh (tiada kredit).

2. **`create_additional_traveller_order(booking_number, cabin_no, category="main_adult")`**:
   - Whitelist kategori (`main_adult` | `extra_bed` | `infant`); nilai luar → `frappe.throw`.
   - Rate dikira semula di server dari `pricing_map` ikut kategori; kredit excess diterapkan pada **Main Adult sahaja** (keputusan anda).
   - Segment pax_type dalam description item SO ikut kategori: `"Main Guest (Additional)"` / `"Extra Bed (Additional)"` / `"Infant (Additional)"` — format `Trip | Group | Kategori Bilik | Cabin N | Pax Type | nota` kekal, jadi layout/aktivasi sedia ada tidak terjejas.
   - SO tetap **insert + submit terus** (behavior "order terus ke Sales Order" dikekalkan); `fully_covered` → aktif slot terus; else pulang `billing_url` seperti sedia ada. Tanpa param `category` → `main_adult` (backward compatible).

3. **`_activate_share_traveller_reservation`** — baca segment pax_type (parts[4]) description dan set `Booking Reservation.pax_type` ikut: `"Extra Bed (Additional)"` → `"Extra Bed"`, `"Infant (Additional)"` → `"Infant"`, lain/lama → `"Main Guest"`.

## B. Frontend — `travel_booking/public/js/traveller_travellers.js`

4. **Buang panel atas & bawah**: `#tvShareSlot` + `loadShareCabins()` + `addShareTraveller()` lama, dan `#tvNewCabinSlot` + `loadNewCabinOptions()` + `addNewCabin()` (keputusan anda: buang juga).

5. **Butang Add Traveller per cabin**: `initListMode()` turut fetch `get_shareable_cabins` (senyap bila gagal; skip bila `price_hidden` — guard B2B kekal) → map ikut `cabin_no`. Dalam `renderSlotList()`, cabin yang `eligible` (ada kekosongan & trip tak penuh) dan room_category-nya sepadan dapat butang **"＋ Add Traveller"** di kanan header cabin.

6. **Modal pilih kategori** (corak overlay sedia ada — seperti `showPassportMismatchModal`): senarai radio Main Adult / Extra Bed / Infant dengan kadar net + nota kredit twin-share bila cabin solo. Butang Confirm → `create_additional_traveller_order(booking_number, cabin_no, category)` → `fully_covered` → alert + reload; else redirect ke `billing_url`.

7. **Header cabin** ditukar dari `<button>` ke `<div role="button" tabindex="0">` (butang tidak boleh bersarang dalam butang); toggle expand/collapse + keyboard Enter/Space dikekalkan.

## C. CSS — `travel_booking/public/css/traveller.css`

8. `button.tv-cabin__header:focus-visible` → `.tv-cabin__header:focus-visible` supaya focus ring kekal berfungsi selepas tukar tag.
