# Pelan: Background Image Homepage + Text Editor dengan Toggle HTML

## Konteks
Semuanya dalam app `travel_booking` (tiada app `travel_website` berasingan). Dua homepage: `/cruise` dan `/tour`, dikawal oleh doctype singleton **Travel Website** (3 tab: Common, Cruise Homepage, Tour Homepage). Dua penemuan penting:

1. **Medan background hero SUDAH wujud** (`cruise_hero_background`, `tour_hero_background` — Attach Image) tetapi **tidak berfungsi**: template letak inline style pada `<section>`, tetapi div anak `.rc-hero-bg` (`position:absolute; inset:0`) menutupnya sepenuhnya dengan gradient hardcoded + imej `cruise-hero-bg.jpg`/`tour-hero-bg.jpg` yang **tidak wujud** dalam `public/img/` (404).
2. Frappe Text Editor tiada butang source-code built-in → toggle perlu JS custom.

## Bahagian 1 — Baiki background hero (kedua-dua homepage)

**`travel_booking/www/cruise.html` + `tour.html`** — alihkan inline style dari `<section>` ke div `.rc-hero-bg` (lapisan yang benar-benar render):
```html
<section class="rc-cruise-hero">
  <div class="rc-hero-bg"{% if hp.hero.background %} style="background-image: url('{{ hp.hero.background }}')"{% endif %}></div>
```
Inline style mengatasi background CSS; overlay gelap `.rc-hero-overlay` + shimmer `::after` kekal untuk kebolehbacaan teks.

**`travel_booking/public/css/cruise.css` + `tour.css`** — buang baris `background-image: url('.../cruise-hero-bg.jpg')` / `tour-hero-bg.jpg` (imej 404 yang turut membuang gradient fallback). Gradient `linear-gradient(135deg,#1a1a2e,...)` kekal sebagai fallback apabila tiada imej di-set (pilihan pengguna).

**`travel_booking/www/index.html`** (fallback root `/`) — tambah conditional background style yang sama pada kedua-dua blok hero (cruise/tour); tambah `hero_background` dalam context `index.py` jika belum ada.

Tiada perubahan Python config diperlukan — `website_config.py` sudah pulangkan `hero.background` dan cache dikosongkan oleh `on_update`.

## Bahagian 2 — Text Editor + toggle Rich Text / HTML

**Skop (jawapan pengguna: "semua title & subtitle dalam both homepage")** — 12 medan setiap tab (×2 = 24):
`hero_title`, `hero_intro`, `featured_title/subtitle`, `whyus_title/subtitle`, `dest_title/subtitle`, `testi_title/subtitle`, `cta_title`, `cta_body` dengan prefix `cruise_` dan `tour_`.

1. **`travel_website.json`** — tukar fieldtype `Text`/`Data` → **Text Editor** bagi 24 medan + tambah `"max_height": 110` supaya editor padat dan borang tidak berat.
2. **`travel_website.js` (fail BAHARU)** — toggle bagi setiap field Text Editor:
   - Butang kecil "Edit HTML" bersebelahan label medan
   - Mod HTML: sorok `.ql-toolbar` + `.ql-container` (Quill), papar `<textarea>` monospace berisi HTML mentah dari `field.get_value()`
   - Taip dalam textarea → debounce sync ke `field.set_value()` (bentuk dirty & save berfungsi walaupun lupa toggle balik)
   - Toggle balik → papar semula Quill dengan HTML yang dikemaskini
3. **Template `cruise.html` + `tour.html`** — tambah `|safe` pada semua medan yang ditukar (hero_title sedia ada); hero intro tukar wrapper `<p>` → `<div class="rc-hero-intro">` (output Quill bermula `<p>` — elak nested-`<p>` yang browser auto-break dan rosak layout).
4. **`cruise.css` + `tour.css`** — pindah styling dari `.rc-hero-content p` ke `.rc-hero-intro` (+ style `.rc-hero-intro p`).
5. **`trip_command_center.js`** (preview website di Desk) — medan yang kini bawa HTML: strip tags dalam preview ringkas supaya tag tak kelihatan mentah.

## Langkah pelaksanaan
1. Edit `travel_website.json` (fieldtype + max_height) → `bench migrate` untuk sync schema
2. Cipta `travel_website.js` dengan toggle
3. Edit kedua template + CSS + index.html/index.py + command center
4. Reload gunicorn via HUP (preload mode)

## Verifikasi
- `curl` halaman `/cruise` & `/tour` — inline style kini pada `.rc-hero-bg`
- Set imej background dalam Desk → save → semak imej dipapar, gradient muncul bila kosong
- Semak CSS di-serv mengandungi perubahan (bukan cache lama)
- Form Desk: toggle Rich Text ⇄ HTML berfungsi, nilai tersimpan selepas save

## Nota risiko
- Nilai Text lama dipaparkan sebagai plain text dalam Quill (newline mungkin collapse) — admin boleh re-edit
- `|safe` selamat kerana hanya System Manager boleh edit doctype ini (role lain read-only)
- Ikut amalan established: verify via curl, JANGAN clear-cache/console (perangkap permission + hooks reload)
