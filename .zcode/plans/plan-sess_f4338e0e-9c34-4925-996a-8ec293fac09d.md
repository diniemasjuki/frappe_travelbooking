## Diagnosis (ringkasan)

Punca bug "Saved tapi tak tersimpan" ialah `trip.py:249` — `self.name = make_autoname(self.naming_series)` di dalam `before_save`. `before_save` Frappe berjalan pada setiap save (insert DAN update). Semasa UPDATE, baris ini menjana `self.name` baharu yang tiada dalam DB → `db_update()` Frappe menjalankan `UPDATE tabTrip ... WHERE name=<nama_baru>` → 0 baris terpadan, tiada exception → notifikasi "Saved" palsu, DB tak berubah.

## Fix: pindah logik naming ke method `autoname(self)` (insert-sahaja)

Fail: `travel_booking/travel_booking_management/doctype/trip/trip.py`

Gantikan `before_save` sekarang dengan dua method berasingan — `autoname` (insert-sahaja) + `before_save` (title/route sahaja, tak sentuh name):

```python
	def autoname(self):
		# Naming siri TRIP.YY.## — Frappe panggil ini sekali semasa insert
		# (via set_new_name, naming.py:191), selepas reset self.name. Override
		# config/Property Setter apa pun → jamin siri. Tak dipanggil semasa update.
		self.name = make_autoname(self.naming_series)

	def before_save(self):
		self.title = self.trip_name.upper()
		self.route = "trip/" + self.trip_name.lower().replace(" ", "-")

	def validate(self):
		pass
```

Perubahan konkret:
1. Buang baris `self.name = make_autoname(self.naming_series)` dari `before_save` (baris 249).
2. Tambah method `autoname(self)` dengan baris tersebut (insert-sahaja — Frappe panggil via `set_new_name` `naming.py:191`).
3. Buang komen `# JANGAN USIK, INI UNTUK SET TRIP CODE YANG PENTING` (merujuk logik name yang kini dipindah ke `autoname`, bukan dibuang).
4. Import `make_autoname` (baris 6) **kekal** — masih digunakan oleh method `autoname` baru.

## Kenapa `autoname(self)` dan bukan `before_insert`
- `before_insert` (`document.py:733`) dipanggil SEBELUM `set_new_name`. `set_new_name` (`naming.py:162`) reset `doc.name = None` → apa yang `before_insert` tetapkan akan dipadam. Naming mesti berlaku DI DALUM `set_new_name` (line 191 `run_method("autoname")`), bukan sebelumnya.
- `autoname(self)` ialah hook standard Frappe khas untuk naming — hanya dipanggil semasa insert (`set_new_name` hanya dipanggil dari `Document.insert()`, bukan `_save()`/update).

## Kesan positif turut diperolehi
- Single burn: `make_autoname` sekali semasa insert (kini ia membakar 2 — config `naming_series` di `naming.py:194` + `before_save` line 249; selepas fix, method `autoname` diset lebih dulu di line 191, jadi config line 194 di-skip → satu bakar sahaja).
- `tabSeries` tak lagi dimajukan setiap kali edit-save gagal (tiada lagi jurang dalam `TRIP.YY.##`).
- API `travel_booking.api.trip_manager.save_trip` (`trip_manager.py:332`, `doc.save()` update) turut sembuh automatik.
