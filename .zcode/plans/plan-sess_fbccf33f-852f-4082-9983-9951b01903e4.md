# Ganti section Cabin Sharing dengan checkbox minimal

## UI baru (ganti 2 kad radio besar dengan 1 checkbox je)

```
┌─ Cabin 1 ─────────────────────┐
│ [Pilih kabin]              ▾  │
│                               │
│ Main Guest     − 1 +          │
│ Extra Bed      − 0 +          │
│ Infant         − 0 +          │
│ ─────────────────────────────│
│ ☐ Find me a roommate          │
│   (same-gender matching)      │
└───────────────────────────────┘
```

- **Tak checked** = Private (default, macam behavior lama).
- **Checked** = "Open Sharing" — kami carikan partner sebilik.
- Diletak di **bawah sekali kad kabin** (selepas counter tetamu).
- **Muncul hanya bila total guest cabin = 1 orang** (main + extra bed + infant). Kabin >1 orang → tak muncul langsung. Kalau user tambah tetemu selepas tick, checkbox auto-uncheck & hilang.

Nilai yang dihantar ke backend TAK BERUBAH ("Open Sharing" / kosong = Private) — jadi alur roommate matching pasca-tempahan kekal berfungsi macam biasa.

   - Auto-hide live: guna array `allStepperRefreshers` sedia ada supaya bila tambah/kurang tetamu, checkbox hilang/papar tanpa re-render penuh.
   - Tukar syarat sama di baris "Room Privacy" dalam summary (line ~2575) dan payload Pay Now (line ~4666).

2. **`api/booking_engine.py`** (line ~349–355): sanitize server ikut syarat baru (`main + extra + infant == 1`) — cegah nilai di-suntik untuk kabin >1 orang.

3. **`public/css/booknow.css`** (~line 1324–1398): buang style kad radio lama, ganti style ringkas untuk checkbox row.
